Sequential construction
  • Throughput stays flat as N grows, so build time grows linearly with N
  • Larger blocks are faster: 284 MB/s at 4 KiB vs 46 MB/s at 32 B
  • Both layouts hash at almost the same speed, but pointer needs 2× memory: 512 vs 256 MiB at N = 2²²
Parallel construction
Up to 47.7×; small trees peak at 16 threads.
A small tree gives each thread too little work (next slide).
Small blocks: only 19.2× (flat: 43.5×).
2N−1 mallocs and pointer arrays add non-hashing work; 4 KiB blocks hide it (44.6×).
Where the parallel time goes
Leaf level: 16,384 nodes for 48 threads, so every thread is busy (10% waiting).
Each level up halves the work, but waiting shrinks more slowly (42% at level 6).
Top 8 levels (< 192 nodes) run on one thread: 116 µs, 28.5% of the build.
Large tree (2²², 4 KiB): 95.1% of the time is leaf hashing, so it scales.
Proof generation
